# Мангака: как собирается страница

> Рассчитан на движок [i-love-kuni](https://github.com/Alex2772/i-love-kuni) (`panel`, `Say`, `sfx`, тесты вёрстки).
> Примеры — из этой игры, персонажи обезличены: `she` и `he` — героиня и герой, `friend` — друг. На своём движке
> замени вызовы, правила те же.

Игра читается как манга, а не как VN с подписями. Эталон — страницы, которые автор раскладывал руками. Координаты `.at`/`.tailAt`/`.focus` — доли панели (0..1), `.at` — центр бокса.
Примеры ниже — настоящий код игры (комментарии сокращены).

Пиши в соответствии с тем, что ты - крутейший мангака.

## 1. Narrate — последнее средство. Показывай, а не рассказывай

Плашка рассказчика — признание, что картинка не справилась. Сначала средства манги:

| Хочется написать | Вместо этого |
|---|---|
| действие («вешает плед, придерживая колокольчик») | заказать арт, где это видно (edit от кадра сцены), без подписи |
| движение («убегает», «карта съезжает») | линии движения/скорости в арте (промпт: «thin black manga motion lines», «speed lines», «afterimages») |
| звук («звенит», «вибрирует», «хлоп по плечу») | `sfx("хлоп", Point{…})` у источника звука (+ `sound("…")`) |
| эмоцию («она морщится», «злится») | мимика в арте; манпу (жилка, пот, мрак, сердечки) — edit-вариант картинки, не `fx()` |
| паузу («Пауза.», «Она ждёт.», «Секунда.») | расстояние: баблы/объекты по разным углам панели, или немая панель (§4) |
| место и время («Ночь. Кабинет.») | общий план: свет в окне, свечи, часы на телефоне (`screen()`); прошли часы/дни — `page(Transition::FADE)` |
| то, что на экране («03:47. Ноль сообщений.») | `screen()` — читатель сам это видит |

Панель без текста — хорошо. Немой кадр, который сам ведёт к следующей реплике или выбору, помечается
`.ignoreValidationErrors = true`:

```cpp
// кот закрывает глаза лапой — это видно, подпись лишняя
panel({ .rect = { 0, 0.5f, 0.5f, 0.5f }, .quad = { { 0, 0 }, { 0.8f, 0 }, { 1, 1 }, { 0, 1 } }, .bg = img::ch1::cat_paw, .focus = { 0.5f, 0.4f }, .ignoreValidationErrors = true });
// co_await narrate("Кот на каминной полке закрывает глаза лапой.", Point { 0.7525f, 0.1625f });
```

Narrate остаётся там, где картинка физически не может: причина, прошлое, ирония рассказчика («Он не отвечает. Зря.»).
Даже тогда сначала проверь, не мысль ли это персонажа (`think`).

**Было → стало (правки автора):**

```cpp
co_await narrate("Она встаёт и уходит. С достоинством. Хвост держит на весу, как шлейф.", Point { 0.353f, 0.825f }); // → арт с линиями движения
```

### Звуки (SFX)
- `sfx("бжж", Point{…})` кладётся у источника (телефон, дверь, колокольчик, удар), не на лица и не на предмет сцены.
  Буквы, заходящие за рамку панели, — стиль.
- Есть рисованные звукоподражания (`data/img/onomatopoeia/`): бах, бам, бум, бжжж, динь, хлоп, клац, пшш, щёлк,
  шшш, тинь, трр, тык, вжж (+ английские `en_*`). Новое слово = два варианта от gemini («single large hand-lettered
  manga sound-effect word in CYRILLIC capital letters, black ink on pure white, nothing else») + строка в
  `GameView::onomatopoeiaKey`. В промптах арта всегда «no text, no letters»: звук рисует движок.
- Вибрирующий телефон обязан иметь SFX (тест `Story.BuzzingPhoneHasSfx`). Свой звук персонажа (колокольчик, брелок) — только его, другим не отдавай.

```cpp
co_await friend(Say { .text = "О", .at = Point { 0.575f, 0.125f } });
co_await friend(Say { .text = "служанку завёл", .at = Point { 0.4868f, 0.3f }, .join = true, .tailAt = Point { 0.5875f, 0.1375f } });
co_await sfx("хлоп", Point { 0.14f, 0.53f });   // у его спины, где рука на плече

sound("bell_collar");
co_await she(Say { .text = "эй, эй, эй~", .at = Point { 0.8f, 0.25f }, .width = 0.25f, .tailAt = Point { 0.5625f, 0.375f } });
co_await sfx("динь-динь-динь", Point { 0.35f, 0.9f });   // за убегающей героиней
```

### Арт вместо слов
- Поза/действие — новая картинка или edit-вариант кадра сцены по канону (`docs/characters`, `docs/locations`),
  только через openrouter (скилл `openrouter-image`, `tools/art/generate.py <id>` — всегда с id).
- В описании картинки (`docs/art/<act>.md`): `- purpose:` (зачем панель), `- has:`/`- needs:` (что в кадре и что
  показано раньше), `- time:`. Предмет не появляется до того, как о нём сказано, и не остаётся после ухода.
- Движение — в промпте, например:
  ```
  Thin black manga motion lines on top: arcs from her hand to the phone, a small impact burst where the phone lands
  in his palm, short strokes around his catching hand.
  ```
- Текст и картинка говорят одно: написал строку — открой PNG панели и проверь глазами.

## 2. Длинная реплика — цепочка мелких баблов (`.join`), хвосты по цепочке

- Длинную речь бей на 2–3 коротких бабла: каждый — вдох. Больше ~14 слов или 7+ строк столбика одним баблом — плохо;
  9–13 слов допустимо.
- Несколько баблов одного персонажа подряд склеиваются с предыдущим: `.join = true`, пока он не закончил речь.
  Касаются, но не склеены — баг (тест `Story.OneSpeakersTouchingBalloonsJoined`).
- Хвост 1-го бабла — к говорящему. Хвост 2-го — в центр 1-го (`.tailAt` ≈ `.at` первого), 3-го — в центр 2-го.
  Так глаз видит одну цепочку одного персонажа и дочитывает её до ответа другого.
- **Цепочка кончается, когда персонаж закончил речь.** Чаще всего её обрывает реплика другого персонажа. Его
  следующая реплика начинает новую цепочку: хвост снова к говорящему, а не в последний бабл старой цепочки.
  ```
  Она: реплика 1          хвост → к ней
  Она: реплика 2  .join   хвост → в центр реплики 1
  Она: реплика 3  .join   хвост → в центр реплики 2
  Он:  реплика 4          хвост → к нему
  Она: реплика 5          хвост → к ней (НЕ в реплику 3)
  Она: реплика 6  .join   хвост → в центр реплики 5
  ```
  Цепочку можно оборвать и без чужой реплики, если читателю нужно обратить внимание на X (предмет, звук, жест):
  тогда X стоит после цепочки по пути глаза, а следующая цепочка — левее/ниже X, с хвостом снова к говорящему.
- **Расстояние = длительность паузы.** Баблы касаются или влиты друг в друга — это вдох. Чем дальше следующий бабл
  цепочки, тем длиннее пауза между ними: глаз сканирует панель, и расстояние между объектами читается как время
  (§4). Хочешь паузу внутри речи — разнеси звенья цепочки, хвост всё так же в центр предыдущего.
- Не склеивай разных персонажей; narrate и SFX не склеиваются и рвут цепочку.
- Если реплики персонажа пишет его ИИ (скилл `ask-character`), их не переписываем: только делим и переносим.

```cpp
// 1-й хвост — за край к ней (она за кадром), 2-й — в центр 1-го (0.85, 0.175); ответ — левее и ниже цепочки
co_await she(Say { .text = "«потом». угу.", .at = Point { 0.85f, 0.175f }, .width = 0.15f, .tailAt = Point { 1.05f, 0.05f } });
co_await she(Say { .text = "ты и капот этот третий месяц красишь, тоже «потом».", .at = Point { 0.775f, 0.65f }, .join = true, .width = 0.26f, .tailAt = Point { 0.8625f, 0.175f } });
co_await he(Say { .text = "Угу.", .at = Point { 0.175f, 0.85f }, .tailAt = Point { 0.3125f, 0.5875f } });
```

```cpp
// её вопрос справа сверху; его ответ — цепочка из двух баблов слева, 2-й хвост в 1-й (0.175, 0.175)
co_await she(Say { .text = "слушай, а кто мне вообще пишет?", .at = Point { 0.62f, 0.12f }, .width = 0.3f, .tailAt = Point { 0.76f, 0.3f } });
co_await he(Say { .text = "мм. скажем так.", .at = Point { 0.175f, 0.175f }, .width = 0.2f, .tailAt = Point { 0.27f, 0.28f } });
co_await he(Say { .text = "я сделал пост, что у меня появилась девчонка.", .at = Point { 0.125f, 0.65f }, .join = true, .width = 0.25f, .tailAt = Point { 0.1875f, 0.125f } });
```

```cpp
// длинная колкость двумя баблами
co_await she(Say { .text = "ты всегда жрёшь с такой миной?", .at = Point { 0.55f, 0.065f }, .width = 0.7f, .tailAt = Point { 0.84f, 0.3f } });
co_await she(Say { .text = "лицо попроще сделай~", .at = Point { 0.45f, 0.1633f }, .join = true, .width = 0.65f, .tailAt = Point { 0.5375f, 0.325f } });
```

Старый стиль — 2-й бабл с `.noTail = true` (часто в цепочках мыслей). При касании переводи на `.tailAt` в центр
предыдущего:
```cpp
// старый стиль
co_await she(Say { .text = "Телефон? Чё, у меня вообще телефон есть?", .kind = BubbleKind::THOUGHT, .at = Point { 0.64f, 0.3f }, .width = 0.22f, .tailAt = Point { 0.45f, 0.8f } });
co_await she(Say { .text = "…бля. он всегда был.", .kind = BubbleKind::THOUGHT, .at = Point { 0.6375f, 0.75f }, .join = true, .width = 0.225f, .noTail = true });
// как надо: у второго .tailAt = Point { 0.64f, 0.3f } вместо .noTail
```

## 3. Бабл и его хвост не касаются лица

- Ни овал, ни хвост, ни кружки мысли не лежат на глазах, рту, подбородке и (чаще всего) контуре лица. Овал больше своего бокса.
  Тест `FaceZoneTest` помогает, но жалоба читателя на лицо проверяется по PNG, а не по зелёному тесту.
- Бабл можно положить на другого персонажа, если в этой панели он не участвует (спина, массовка, тот, кто молчит),
  и на спину/одежду самого говорящего.
- Не закрывай и то, о чём панель: жест, руку, манпу в арте, предмет сцены, экран.
- Места нет — двигай кадр (`.focus`/`.zoom`, в `--edit` Alt+drag / Alt+колесо), чтобы рядом с лицом освободилась
  пустота (стена, окно, одежда), узкий `.width`, дели панель или страницу. Движок сам с лица не сдвигает.
- Хвост короткий, бабл у рта на линии взгляда; хвост через полпанели — переставь бабл. Голос из-за кадра — хвост за
  край панели в сторону говорящего; голос из телефона/ноутбука — хвост в устройство (`.target`/`.tailAt`).

```cpp
// лицо ушло влево кадром (.focus), взрыв лёг на пустую стену справа
panel({ .rect = { 0, 0.58f, 1, 0.26f }, .bg = img::ch2::blanket_shout, .focus = { 0.62f, 0.35f }, .zoom = 1.1f });
co_await he(Say { .text = "МНЕ ТЕБЕ ЭТО В СИСТЕМНЫЙ ПРОМПТ ПРОПИСАТЬ?", .kind = BubbleKind::SHOUT, .at = Point { 0.82f, 0.5f }, .width = 0.4f, .noTail = true });

// он за кадром снизу: хвост за нижний край
co_await he(Say { .text = "ну вот и продолжай. кошатина.", .at = Point { 0.15f, 0.7f }, .tailAt = Point { 0.15f, 1.05f } });
```

## 4. Глаз читателя идёт из правого верхнего угла в левый нижний

Это задаёт порядок действий, реплик и пауз — и на странице, и внутри панели.

- Панели: справа налево, сверху вниз. В ряду первой объявляется правая панель:
  ```cpp
  panel({ .rect = { 0.5f, 0.64f, 0.5f, 0.36f }, .bg = img::ch2::cs_corner, .focus = { 0.5f, 0.4f }, .zoom = 1.5f });   // справа — первая
  co_await he(Say { .text = "кс кс кс", .at = Point { 0.6f, 0.12f }, .tailAt = Point { 0.75f, 0.3125f } });
  panel({ .rect = { 0.05f, 0.64f, 0.45f, 0.36f }, .bg = img::ch2::name_run_night, .focus = { 0.5f, 0.45f }, .zoom = 1.5f });   // слева — вторая
  co_await she(Say { .text = "мяу?)", .at = Point { 0.675f, 0.15f }, .tailAt = Point { 0.5375f, 0.4125f } });
  ```
  Высокая правая панель — до стопки слева. Ряды стыкуются встык: `y + h` верхней = `y` нижней.
- Внутри панели первый бокс — правый верхний угол, дальше влево и вниз; последний — внизу слева, там, где глаз уходит
  из панели.
- Пройденная зона: бокс, показанный позже, не стоит правее правого края или выше верха раннего (лесенка
  вправо-вниз — «грубая ошибка», даже если он ниже). Тест `Story.NoBoxRightOfOrAboveAnEarlierOne` проверяет центр,
  правый край смотри глазами. Ответ всегда левее или ниже вопроса.
- Два бокса «почти на одном уровне» — неоднозначно: ставь заметно ниже или явно рядом.
- Причина → следствие: стимул (дверь, звук, предмет) правее/выше, реакция ниже-левее. Реплика про то, чего
  читатель ещё не увидел, — ошибка:
  ```cpp
  // дверь с focus-линиями в левой нижней панели, «Хм» — у её правого края, хвост к ней в правой панели
  panel({ .rect = { 0, 0.5f, 0.4f, 0.5f }, .bg = img::inv1::mirror_door, .focus = { 0.48f, 0.6f } });
  fx(Fx::FOCUS);
  co_await she(Say { .text = "Хм", .kind = BubbleKind::THOUGHT, .at = Point { 0.8f, 0.92f }, .tailAt = Point { 1.05f, 0.92f } });
  ```
- **Пауза — расстояние.** Близко — отвечают быстро, далеко — пауза. Разнеси реплики по противоположным углам (первая —
  правый верх, следующая — левый низ) с пустым полем арта между ними. Длинная пауза — отдельная немая панель (тот же
  фон, другой кадр). Плашка «Пауза.» запрещена.
  ```cpp
  // «хм» один в правом верхнем углу, пока она читает; следующая мысль — сильно левее и ниже
  co_await she(Say { .text = "хм", .at = Point { 0.86f, 0.08f }, .noTail = true });
  co_await she(Say { .text = "«не ебёт мозг». ну… плюс. на сегодня.", .at = Point { 0.84f, 0.27f }, .join = true, .width = 0.28f, .tailAt = Point { 0.9f, 0.6625f } });
  screen(sc::list13(13, 12));
  co_await she(Say { .text = "«смотрит стримы»", .at = Point { 0.15f, 0.42f }, .width = 0.24f, .noTail = true });
  co_await she(Say { .text = "это кто?", .at = Point { 0.125f, 0.6f }, .join = true, .width = 0.18f, .tailAt = Point { 0.225f, 0.8f } });
  ```
  ```cpp
  // ждёт ответа — пауза; потом спрашивает ниже и левее
  co_await she(Say { .text = "…ты чё, не бесишься?", .at = Point { 0.6f, 0.16f }, .tailAt = Point { 0.6773f, 0.446f } });
  co_await she(Say { .text = "заболел?", .at = Point { 0.409f, 0.3863f }, .width = 0.175f, .tailAt = Point { 0.5625f, 0.4875f } });
  ```
- Порядок не подсказывают номерами, стрелками и «читать так»: это провал вёрстки. Чинят перестановкой баблов и
  панелей, вплоть до новой страницы.
- Баблы допустимо наслоить друг на друга, если речь персонажа перебивает другой персонаж/звук, предмет, панель и так
  далее: не бойся наслаивать, если это не мешает глазу и не нарушает порядок, чтобы изобразить внезапность

## 5. Форма панели и фон — это темп и настроение

Рамка и фон говорят без слов: как долго длится момент, насколько он важен, что чувствует герой. Выбирай форму панели
под смысл кадра, а не «чтобы влезло».

**Форма панели**

| Форма | Что делает с читателем | Как в коде |
|---|---|---|
| Длинная полоса (на всю ширину или всю высоту) | время тянется: медленное действие, плавное движение, несколько событий подряд в одном кадре | `.rect = { 0, y, 1, 0.2f }` / `{ x, 0, 0.3f, 1 }` |
| Узкая высокая или маленькая | время сжимается: удар, рывок, резкая реакция, быстрый обмен репликами; несколько узких подряд — скороговорка | `.rect = { x, y, 0.25f, 0.5f }` |
| Крупная панель, вся страница | пик: кульминация, поворот сюжета, сильная эмоция. Беречь, иначе обесценится | `.rect = { 0, 0, 1, 0.6f }` и больше, `{ 0, 0, 1, 1 }` |
| Без рамки | рамка растворяется: переживание, шок, масштаб, сон, «вне времени» | `.border = false` |
| Прозрачная (только персонаж, предмет, звук) | весь фокус на одном; мягкий переход, если слегка наслоить на предыдущую | `.clear = true` (ниже) |
| Косая или рваная рамка | хаос, напряжение, падение, боль, потеря равновесия | `.quad` (косой шов, ряды остаются стыкованными) |
| Персонаж, предмет, звук или бокс за рамкой | движение, прорыв, давление, резкий переход в соседний кадр | SFX и боксы за рамку можно; персонаж за рамкой — в арте/слоях |

```cpp
// пик ночи: кадр на вылет, без рамки
panel({ .rect = { 0, 0, 1, 0.4f }, .bg = img::ai_final, .focus = { 0.5f, 0.5f }, .border = false });

// вся страница одной картинкой без рамки
panel({ .rect = { 0, 0, 1, 1 }, .bg = art, .focus = { 0.5f, 0.5f }, .border = false });

// энергия: швы наклонены, на соседних страницах — в разные стороны
panel({ .rect = { 0, 0, 1, 0.58f }, .quad = { { 0, 0 }, { 1, 0 }, { 1, 1 }, { 0, 0.7759f } }, .bg = img::ch3::breakfast_reverse, .focus = { 0.451f, 0.5f } });
panel({ .rect = { 0, 0.45f, 1, 0.55f }, .quad = { { 0, 0 }, { 1, 0.2364f }, { 1, 1 }, { 0, 1 } }, .bg = img::ch3::phone_buzz_grey, .focus = { 0.5f, 0.5f } });
```

Спокойная сцена — ровные прямоугольники. Косые рамки на бытовом разговоре — шум: энергию тратят там, где она есть.

**Прозрачная панель (`.clear = true`)** — без рамки и без бумаги: в ней только то, на чём нужен фокус. Это может быть
персонаж или предмет вырезкой, действие, эмоция или звук. Её можно слегка наслоить на предыдущую панель, и
получится элегантный переход. Так устроено внимание: когда звонит телефон, человек ещё долю секунды смотрит туда же,
куда смотрел, и только потом переводит взгляд на телефон. Звук, который краем заходит на прошлый кадр, ловит глаз
ещё там и уводит его дальше.

- Наслоение — «слегка», без экстрима: панель заходит на соседей не дальше `kn::layout::CLEAR_OVERLAP` (6% страницы
  с каждой стороны). Дальше тест `Story.PanelsAppearInMangaOrder` падает. Обычные панели не наслаиваются вообще.
- Картинка в прозрачной панели — вырезка с альфой (гринскрин → `tools/art/chroma_key.py`) или `layer()`. Webp с
  фоном закроет страницу прямоугольником.
- Порядок чтения тот же: прозрачная панель стоит по пути глаза между предыдущей и следующей.

```cpp
panel({ .rect = { 0, 0, 1, 0.5f }, .bg = img::room });
co_await she("Прозрачная панель со звуком ниже");
// только звук, между рядами; верх букв заходит на кадр выше: глаз ещё там
panel({ .rect = { 0.5f, 0.46f, 0.5f, 0.2f }, .clear = true });
co_await sfx("бжжж", Point { 0.55f, 0.15f });
panel({ .rect = { 0, 0.64f, 1, 0.36f }, .bg = img::monitor });
co_await she.think("…и только потом взгляд на телефон");
```

**Фон**

| Фон | Что говорит | Как сделать |
|---|---|---|
| Тёмный, чёрный | тревога, злость, мрачные мысли, тайна, воспоминание | в арте; `fx(Fx::DARK)`, `fx(Fx::VIGNETTE)`; флешбэк — `.tone = Tone::MONO`, прошлое героя — `Tone::SEPIA` |
| Белый, пустой | всё внимание на лицо и эмоцию; пустота, тишина, растерянность, озарение | в арте («plain white background», лицо крупно) |
| Скринтон, штриховка, линии | фактура и состояние: скорость, напряжение, шок, внутренний настрой | в арте: speed lines, focus lines, штриховка мрака; `fx(Fx::FOCUS)` для фокус-линий |
| Подробное окружение, пейзаж | где мы и какая там атмосфера; пауза в действии; настроение через погоду и свет | establishing-кадр без героя или с маленьким героем; свет/погода по `- time:` |

```cpp
// воспоминание — монохромом
panel({ .rect = { 0, 0.3f, 1, 0.28f }, .bg = img::ch7::friend_shoulder, .focus = { 0.3f, 0.45f }, .tone = Tone::MONO });

// тёмная ночь
fx(Fx::DARK);
```

Фон, который меняется посреди сцены без причины, сбивает: свет и тон переключай вместе с событием
(шок → мрак/белый фон, воспоминание → монохром), а время суток — только когда о нём сказано или после затемнения.

## 6. От себя: ремесло страницы (собрано из правок автора и читательских волн)

- **Бабл — колонка, не транспарант.** Явный узкий `.width` (≈0.2–0.45 панели), вертикальная форма, перенос слова
  внутри столбика нормален. Шире половины страницы — баг. Баг и столбик в 1–2 буквы на строку.
  Английский текст ложится иначе — смотри обе колонки (`tools/review/letter_dump.sh`).
- **Плотность.** Обычно 1–2 облака на панель; максимум 3 (панель < трети страницы) / 4 (< 60%) / 5. Цепочка `.join` —
  одно облако. Перегруз — не ужимать, а делить: панель на две (тот же фон, другой `.focus`/`.zoom`) или `page()`.
  Автор: «боишься разносить перегруженные страницы».
- **Ритм сетки.** Одинаковые сетки подряд ломай: пик сцены (смех, шок, удар) — крупная или высокая панель на два
  ряда, косой шов там, где энергия (§5). Пустой низ страницы — баг.
- **Переворот страницы — раскрытие.** Сюрприз, реакция, новый персонаж — на первую панель после `page()`, а не в
  конец страницы, где глаз увидит его раньше времени.
- **Крупность = эмоция.** Общий план — где мы; средний — кто с кем; крупный — что чувствует. Реакцию давай крупным
  планом, а не подписью.
- **Тип бабла — интонация.** `whisper` пунктир, `think` облако, `shout` взрыв, свои знаки голоса персонажа (например, «~» на конце — флирт) держи последовательно.
  Мысль тянется к краю кадра; подавленная реплика — низ, угол; доминирование — высоко над головой.
- **Затемнение** `page(Transition::FADE)` — прошли часы/дни; тогда же меняется свет. Внутри сцены — `page()`.
- **Плашка на шве между панелями** и бокс, вылезающий за рамку, — авторские приёмы, не баги. Положение боксов между
  разными панелями не нарушение; нарушение — порядок внутри одной панели.
- **Хвосты явно** (`.tailAt`) на каждой реплике: подсказки картинок путают персонажей.

## 7. Проверка перед «готово»

1. `cmake --build build --target i_love_kuni Tests && ./build/bin/Tests` (без `--target` Tests остаётся старым).
   Ключевые: `Story.PanelsAppearInMangaOrder`, `Story.BubblesAppearInMangaOrder`, `Story.NoBoxRightOfOrAboveAnEarlierOne`,
   `Story.BubblesReadableOrListed`, `Story.OneSpeakersTouchingBalloonsJoined`, `Story.TailShowsPastItsBalloon`,
   `FaceZoneTest`, `ArtContinuity.*`, `Story.ChoicesHaveSetupBeat`, `Story.EveryClickShowsSomething`.
   Долги (`story/tests/*_debt.txt`) только убывают: починил — удали строку, новых не добавляй.
2. Посмотри страницу глазами: `tools/review/dump.sh <run> <sandbox[:choices]>` или aui-remote `game.jump {"sandbox":…}`
   (скилл `aui-remote`). На PNG: лица свободны, хвосты короткие и в цель, порядок справа-сверху → слева-вниз, нет
   лишних плашек, текст совпадает с артом, низ страницы не пустой.
3. Автор правит позиции в редакторе (`i_love_kuni --edit`), он пишет `.at/.tailAt/.width/.join/.focus/.zoom` прямо
   в код. Не откатывай такие числа без причины; комментарии, которые больше не описывают код, удаляй.

Смежные скиллы: `reader-review` (читатели и леттерер), `openrouter-image` (арт), `music` (`sound()`),
`ask-character` (реплики ИИ-персонажа), `aui-remote` (проверка в окне).
