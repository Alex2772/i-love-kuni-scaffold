# Места: планы и референсы

Место фиксируется **до** того, как по нему рисуют панели: иначе окно на соседних кадрах то слева, то справа, а
лишние предметы появляются у края кадра. У каждого места есть план (что на какой стене, где окна и двери, откуда
свет), список ракурсов и канонические картинки. Любая новая панель в этом месте строится от них
(`docs/art/README.md`, «Канон»).

Перед новой картинкой сверь ракурс с планом: если камера смотрит на стену без окон, окон на картинке нет. Нужен
ракурс, которого нет, — сначала допиши его сюда.
