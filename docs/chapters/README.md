# Главы (шаблон)

По файлу на главу: `docs/chapters/<NN>-<имя>.md`. Агент пишет сцены по нему, рецензент-читатель сверяется с ним.

```
# Глава N «Название» · ~20 мин

## Зачем эта глава
что меняется в героях; что игрок должен понять к концу

## Сцены
1. **Место, время.** Что происходит. Кто говорит. ⭐ выбор: вариант А (→ последствие) / вариант Б.
2. ...

## Что запоминается дальше
флаги и события, на которые ответят следующие главы

## Арт
новые места и предметы (сначала канон в docs/locations, docs/props), ключевые кадры
```
