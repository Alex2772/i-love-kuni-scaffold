# Персонажи

Каждый персонаж — папка `<id>/`:
- `README.md` — канон: внешность, характер, голос, чего персонаж никогда не делает, раздел `## Референсы` (какие
  файлы канон и для чего) и `appearance prompt` для генератора.
- `*.png|jpg|webp` — референсы: минимум лицо и полный рост на белом фоне. Если у персонажа несколько обликов (другая
  одежда, другая эпоха), у каждого свой файл, и в README сказано, где какой.

Новый персонаж сначала получает референсы и README, и только потом первую панель (`docs/art/README.md`, «Канон»).
